# lamusica для Android

Сборки мобильного клиента [lamusica](https://github.com/salenyo/lamusica-app).

## Установка

1. Скачайте `.apk` из [последнего релиза](https://github.com/salenyo/lamusica-mobile-releases/releases/latest)
2. Откройте файл на телефоне
3. Разрешите установку из этого источника, если Android попросит

**Требования:** Android 7.0 (API 24) и новее, arm64-v8a или armeabi-v7a.

## Обновления

Приложение проверяет обновления само — «Настройки → О приложении → Проверить».
Клиент читает `latest.json` из последнего релиза этого репозитория.

Здесь публикуются только сборки. Исходный код лежит в приватном репозитории.
