# lamusica для iOS и Android

Мобильный плеер: поиск и прослушивание из YouTube, SoundCloud и Яндекс.Музыки
прямо с телефона — с фоновым воспроизведением, экраном блокировки и офлайн-кешем.

## Возможности

- Поиск по YouTube, SoundCloud и Яндекс.Музыке из одной строки
- Лайки, плейлисты, фильтр по жанрам
- Чарты и рекомендации по прослушанному
- Текст песни с подсветкой строки под текущий момент
- 10-полосный эквалайзер с пресетами и визуализатор
- Музыка играет в фоне; управление — с экрана блокировки, из шторки, с наушников
  и с Bluetooth
- Кеш треков с настраиваемым лимитом: прослушанное открывается без сети
- Светлая и тёмная темы, свой акцент и фон, пять языков интерфейса

## Установка на Android

| Шаг | Что сделать |
|-----|-------------|
| **1** | Скачайте нужный `.apk` из релиза |
| **2** | Откройте файл на телефоне — Android спросит разрешение на установку из этого источника |
| **3** | Разрешите и подтвердите установку |

При первом запуске приложение попросит разрешение на уведомления. Оно нужно
только для карточки плеера в шторке: без него музыка играет, но управлять ею из
шторки не выйдет.

## Установка на iOS

В App Store приложения нет, а `.ipa` **намеренно не подписан** — подписать его
своим Apple ID должны вы. Это обычный путь для приложений вне магазина, и
настраивается он один раз.

### Через AltStore

1. Поставьте **AltServer** на компьютер — [altstore.io](https://altstore.io).
   Нужен Windows или macOS; на Windows дополнительно iTunes и iCloud с сайта
   Apple, а не из Microsoft Store.
2. Подключите iPhone кабелем, в меню AltServer выберите **Install AltStore** и
   войдите своим Apple ID. На телефоне появится приложение AltStore.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** — найдите
   свой профиль и нажмите **Доверять**. Без этого шага ничего не запустится.
4. Скачайте `Lamusica-<версия>-ios.ipa` на телефон.
5. Откройте AltStore → вкладка **My Apps** → **+** в углу → выберите скачанный
   файл. AltStore подпишет его и установит.

### О чём стоит знать заранее

- **Бесплатный Apple ID подписывает на 7 дней.** Дальше приложение перестаёт
  открываться, пока AltStore не обновит подпись. Он делает это сам, когда
  телефон и компьютер с AltServer в одной сети Wi-Fi, — достаточно включать
  компьютер раз в неделю. Платный аккаунт разработчика продлевает срок до года.
- **Бесплатный аккаунт разрешает три приложения одновременно**, и сам AltStore —
  одно из них.
- **Обновление** — это установка нового `.ipa` тем же способом поверх старого.
  Данные и вход сохраняются.

### Если компьютера под рукой нет

**SideStore** — форк AltStore, который после первичной настройки обновляет
подпись сам, без компьютера в сети. Установка `.ipa` в нём такая же.

| | |

| **iOS** | 18.0 и новее |

## Обновления

Встроенного обновления в мобильной версии нет — оно есть только в десктопной.
Новая версия появляется здесь, в релизах: на Android поставьте новый `.apk`
поверх старого (ключ подписи тот же, данные сохранятся), на iOS переустановите
`.ipa` через AltStore.

## Аккаунт

Аккаунт общий с десктопной версией: плейлисты, лайки и история синхронизируются.
Регистрация пока по бета-коду — его выдаёт администратор.
